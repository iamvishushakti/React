## 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/iamvishushakti/React.git
```

Go to any project folder

```bash
cd project-folder-name
```

Install dependencies

```bash
npm install
```

Run the project

```bash
npm start
```

or (for Vite projects)

```bash
npm run dev
```
